# 📊 Data Analytics Project using Databricks (Lakehouse Architecture)

## 🚀 Overview
This project demonstrates an end-to-end data analytics workflow using Databricks. It covers data exploration, dashboard creation, and AI-powered data interaction, simulating real-world analytics use cases.

The goal of this project is to extract business insights from sales and customer data and present them through interactive dashboards.

## 🧠 Project Objectives
- Explore structured data using SQL in Databricks
- Analyze sales, customers, and product performance
- Build interactive dashboards for business insights
- Enable natural language querying using AI (Genie)

---

## 🛠️ Tech Stack
- **Databricks SQL**
- **SQL**
- **Databricks Dashboards**
- **AI Genie (Natural Language Querying)**
- **PySpark (optional)**

---

## 🔍 Phase 1: Data Exploration
- Queried datasets using Databricks SQL Editor
- Explored:
  - Customers
  - Products
  - Orders
- Calculated key metrics:
  - Total Sales
  - Total Orders
  - Total Customers
- Identified trends and patterns in the data

---

## 📊 Phase 2: Data Visualization
- Converted SQL queries into visualizations
- Built charts:
  - Bar charts
  - Line charts
  - Pie charts
- Created dashboard:
  - **Exploring Sales Data**
- Added filters for dynamic analysis

---

## 📈 Phase 3: Business Dashboards

### Sales Dashboard
- Total Sales  
- Total Profit  
- Total Quantity  
- Sales Trend (Monthly)  
- Sales by Category  

### Customer Dashboard
- Total Customers  
- Average Sales per Customer  
- Total Orders  
- Orders by Age Group  
- Top 10 Customers by Sales  

---

## 🤖 Phase 4: AI-Powered Analytics (Genie)
- Created AI chatbot interface for data interaction  
- Asked natural language questions like:
  - "What is the total sales this month?"
  - "Who are the top customers?"
- Reviewed generated SQL queries  
- Improved accuracy through feedback and tuning  

---

## 💡 Key Insights
- Identified top-performing product categories  
- Analyzed customer purchasing behavior  
- Discovered trends in sales over time  
- Enabled faster decision-making using dashboards

- Writing optimized SQL queries for analytics
